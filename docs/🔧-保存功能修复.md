# 🔧 保存功能修复说明

## 📅 修复日期
2025-10-21 21:37

---

## ❌ 之前的问题

### 问题描述
点击"保存"按钮后：
- ❌ **无法选择保存路径** - 文件自动保存到浏览器默认下载目录
- ❌ **无法自定义文件名** - 固定为 `ansi-output.txt`
- ❌ **不知道文件保存在哪** - 没有明确提示

### 原因
使用的是 **Web版本的保存实现**，适用于浏览器环境，但不适合Tauri桌面应用：

**之前的代码**:
```javascript
const saveToFile = () => {
  const blob = new Blob([ansiOutput], { type: 'text/plain' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'ansi-output.txt';  // ❌ 固定文件名
  a.click();  // ❌ 浏览器默认下载，无法选择路径
  URL.revokeObjectURL(url);
  setSuccess('文件已保存！');  // ❌ 不知道保存到哪里
};
```

---

## ✅ 修复方案

### 新功能
- ✅ **原生保存对话框** - 弹出系统级的文件保存对话框
- ✅ **自由选择路径** - 可以选择任意目录保存文件
- ✅ **自定义文件名** - 可以修改文件名
- ✅ **文件类型过滤** - 支持 `.txt` 和 `.ansi` 格式
- ✅ **明确的保存提示** - 显示完整的保存路径

### 修改的文件

**1. src/App.jsx - 导入部分**
```javascript
// 添加 save 和 writeTextFile
import { open, save } from '@tauri-apps/plugin-dialog';
import { readFile, writeTextFile } from '@tauri-apps/plugin-fs';
```

**2. src/App.jsx - saveToFile函数**
```javascript
const saveToFile = async () => {
  try {
    // ✅ 原生保存对话框，用户可以选择路径和文件名
    const filePath = await save({
      defaultPath: 'ansi-output.txt',  // 默认文件名
      filters: [{
        name: 'Text Files',
        extensions: ['txt', 'ansi']  // 支持的文件类型
      }]
    });
    
    if (filePath) {
      // ✅ 保存到用户选择的位置
      await writeTextFile(filePath, ansiOutput);
      
      // ✅ 显示完整的保存路径
      setSuccess(`文件已保存到: ${filePath}`);
      setTimeout(() => setSuccess(''), 3000);
    }
  } catch (err) {
    console.error('Failed to save file:', err);
    setError('保存文件失败');
    setTimeout(() => setError(''), 3000);
  }
};
```

## 🎯 使用方法

### 保存ANSI输出

1. **转换图片**
   - 选择图片
   - 等待转换完成
   - 右侧显示ANSI艺术

2. **点击"保存"按钮**
   - 弹出**原生保存对话框**
   
   ![保存对话框示例]
   ```
   ┌─────────────────────────────────┐
   │  保存文件                        │
   ├─────────────────────────────────┤
   │  📁 位置: /home/zag/Documents   │
   │  📄 文件名: ansi-output.txt     │
   │  📋 类型: Text Files (*.txt)    │
   │                                  │
   │  [取消]           [保存]        │
   └─────────────────────────────────┘
   ```

3. **选择保存位置**
   - 可以浏览任意目录
   - 可以修改文件名（如 `fedora-logo.txt`）
   - 可以选择文件类型（`.txt` 或 `.ansi`）

4. **点击"保存"**
   - 文件保存到你选择的位置
   - 显示提示：`文件已保存到: /home/zag/Documents/fedora-logo.txt`

## 🚀 快速分发指南

### 分发单个文件（最简单）

**推荐: AppImage**
```bash
# 只需分发这一个文件
Chafa-GUI-1.0.0-x86_64.AppImage (3.5MB)

用户使用:
1. 下载文件
2. chmod +x Chafa-GUI-1.0.0-x86_64.AppImage
3. 双击运行 或 ./Chafa-GUI-1.0.0-x86_64.AppImage
```

### 分发完整包（推荐）

```bash
# 创建发布包
mkdir chafa-gui-v1.0.0-release
cp "src-tauri/target/release/bundle/rpm/Chafa GUI-1.0.0-1.x86_64.rpm" \
   chafa-gui-v1.0.0-release/chafa-gui-1.0.0.rpm
cp Chafa-GUI-1.0.0-x86_64.AppImage \
   chafa-gui-v1.0.0-release/
cp src-tauri/target/release/chafa-gui \
   chafa-gui-v1.0.0-release/chafa-gui-binary

# 添加README
cat > chafa-gui-v1.0.0-release/README.txt << 'EOF'
Chafa GUI v1.0.0 - 图片转ANSI艺术工具

📦 包含文件:
- chafa-gui-1.0.0.rpm         (Fedora/RHEL用户)
- Chafa-GUI-1.0.0-x86_64.AppImage  (通用便携版)
- chafa-gui-binary            (原始可执行文件)

🚀 快速开始:
1. Fedora: sudo rpm -ivh chafa-gui-1.0.0.rpm
2. 其他: chmod +x Chafa-GUI-1.0.0-x86_64.AppImage && ./Chafa-GUI-1.0.0-x86_64.AppImage

📋 系统要求:
- chafa (图片转换引擎)
- webkit2gtk4.1 (通常已安装)
- gtk3 (通常已安装)

💡 安装chafa: sudo dnf install chafa

🌐 项目主页: https://github.com/yourusername/chafa-gui
EOF

# 打包
tar czf chafa-gui-v1.0.0-release.tar.gz chafa-gui-v1.0.0-release/
zip -r chafa-gui-v1.0.0-release.zip chafa-gui-v1.0.0-release/

echo "✅ 发布包已创建:"
ls -lh chafa-gui-v1.0.0-release.*
```

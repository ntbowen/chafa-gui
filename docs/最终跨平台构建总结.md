## 🛠️ 构建方式汇总

### 本地构建（Linux 主机上）

```bash
# Linux x86-64
npm run tauri:build

# Windows x86-64 (交叉编译)
./setup-windows-cross-compile.sh  # 一次性
./build-windows.sh
```

### 云端构建（GitHub Actions）

```bash
# macOS Intel + Apple Silicon
git push origin main

# 或创建版本发布（所有平台）
git tag v1.0.0
git push origin v1.0.0
```

### ARM 设备构建

```bash
# 在 x86 机器上打包
./打包源码-传输到ARM.sh

# 传输到 ARM 设备
scp chafa-gui-source.tar.gz pi@raspberrypi:~/

# 在 ARM 设备上构建
ssh pi@raspberrypi
tar xzf chafa-gui-source.tar.gz && cd chafa-gui
npm install && npm run tauri:build
```

## 🚀 自动化构建流程

### GitHub Actions 工作流

已创建两个工作流文件：

1. **`.github/workflows/build-macos.yml`**
   - 专门构建 macOS（Intel + Apple Silicon）
   - 每次推送自动触发
   - 手动触发支持

2. **`.github/workflows/build-all-platforms.yml`**
   - 构建所有平台
   - 创建 tag 时触发
   - 自动创建 GitHub Release

### 触发方式

**推送代码（macOS 构建）**:
```bash
git push origin main
```

**发布版本（全平台构建）**:
```bash
git tag v1.0.0
git push origin v1.0.0
# 自动构建并创建 Release
```

**手动触发**:
- 访问 GitHub Actions 页面
- 点击 "Run workflow"
